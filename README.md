# 9r4n4y_NOTES
A cross-platform, open-source, local-first Markdown notes app. Supports code, images, image editing, folders, labels, checklists, and more. Notes and attachments are stored as ordinary local files, with a simple, smooth UI. Use it as a web app or compile the same source into an Android APK.
